# Evaluations

Versioned directories under `evals/` are frozen historical evidence, not active
product guidance. Their terminology records the product and research contract at
the pinned source revision. Published contracts, fixtures, event schemas, and
reports must remain unchanged; a materially different evaluation starts in a new
versioned directory.

Use the root [README](../README.md), [technical reference](../DOCS.md), and
[domain glossary](../CONTEXT.md) for the current supported product.
